## 📌 هدف الدرس التوضيحي

يوضح هذا الدرس التوضيحي الخطوات اللازمة **لإنشاء ونشر خدمة ويب Java EE (J2EE)** باستخدام:

* بيئة التطوير المتكاملة **NetBeans 6.5**
* خادم التطبيقات المدمج **GlassFish**

كما يوضح كيفية تطوير واختبار **أنواع مختلفة من العملاء** الذين يستخدمون خدمة الويب هذه:
* عميل Java
* عميل C#
* عميل ASP.NET
* عميل Flex

لا يتم شرح الكود سطراً سطراً. لذلك، فإن هذا المستند مخصص للمطورين الذين لديهم بالفعل خبرة مع:
* Java EE
* EJB 3
* JPA
* NetBeans

## 🏗️ محتويات الدورة

يتناول البرنامج التعليمي، على وجه الخصوص:

* تصميم خدمة ويب Java EE
* النشر على خادم GlassFish
* الوصول إلى البيانات عبر JPA
* استخدام خدمة الويب في بيئات تقنية مختلفة:
  * Java SE
  * .NET (C#, ASP.NET)
  * Flex
يُفترض أن المفاهيم الأساسية المستخدمة (EJB3، JPA، بنية Java EE) معروفة بالفعل أو تمت معالجتها في الموارد الإضافية المذكورة في الدرس التعليمي.
